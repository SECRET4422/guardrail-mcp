Hybrid engines that catch real issues

Not one brittle regex. GuardRail stacks complementary analyzers and dedupes results for cleaner agent output.

RX

Secret & pattern grid

AWS keys, tokens, webhooks, PEM blocks, TLS verify-off, and high-signal sink patterns.

AST

Python AST

eval/exec aliases, shell=True, pickle, yaml.load, SQL interpolation with line-level evidence.

TN

Multi-hop taint

Tracks request/input → variables → sinks across assignments with sanitizer awareness.

TS

Tree-sitter

Structural sinks across Python, JS, Go, Java, C/C++, Rust — more robust than pure text search.

PL

Plugins & rules

YAML/JSON custom rules and Python plugins so orgs encode their own security policy.

CI

Repo · Diff · Cache

Parallel repository walks, git PR mode, incremental content-hash cache for monorepos.

Install in minutes

Open source on GitHub. Works locally over STDIO or hosted via MCPize.

Local / Cursor / Claude

mcp.json 
{
  "mcpServers": {
    "guardrail": {
      "command": "python",
      "args": ["-m", "guardrail", "--mode", "stdio"],
      "cwd": "/path/to/guardrail-mcp",
      "env": { "PYTHONPATH": "/path/to/guardrail-mcp" }
    }
  }
}

Clone & test

terminal 
git clone https://github.com/SECRET4422/guardrail-mcp.git
cd guardrail-mcp
pip install -r requirements.txt
export PYTHONPATH=$PWD
python -m unittest discover -s tests -v
python -m guardrail --mode stdio
