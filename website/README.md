# GuardRail marketing website

Professional landing page for GuardRail Security MCP.

## Preview locally

```bash
cd website
python -m http.server 8080
# open http://127.0.0.1:8080
```

Or open `index.html` directly in a browser (relative assets under `assets/web/`).

## Deploy

- **GitHub Pages:** enable Pages on `/website` or copy contents to `docs/` site root
- **Netlify / Vercel / Cloudflare Pages:** publish the `website/` folder
- **Any static host:** upload `index.html`, `css/`, `js/`, `assets/`

## Brand assets

Optimized images live in `assets/web/` (generated from `../assets/`).
